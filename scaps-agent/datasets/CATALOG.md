# SCAPS dataset catalog — phase 12, 2026-11-19

SCAPS 3.3.12. One row per top-level dataset directory, including failed and exploratory acquisitions.
This is an index, not a blanket golden-data certificate. Exact device, defect, contact, optical and numerical
settings remain in the linked params and native .def/.act/.sbf snapshots. Batch overrides are effective per member.
Conditions below reproduce metadata field names and units; native energies may remain explicitly labelled eV.
Raw measurements and clean SI CSV are separate; use the phase report to select columns and fitting windows.

Selection: CapLab AS/Walter → phase 3/7; CV → phase 3/5/8; JFM IV(T) → phase 2/9;
scaps_core → phase 1/5/10 and accepted phase-11 members. Phase 8 supplies CV controls for future DLCP,
not finite-amplitude DLCP data. There are no C(t)/DLTS or general external-RLC reference measurements here.
Phase 6 embeds six older source datasets; these copies are not extra independent experiments.

Quality restrictions: INVALID rows are failure fixtures only; EXPLORATORY is not certified.
Phase 2 reverse 200/220 K is unresolved. GB/G2 CV current columns are stale and excluded from clean CSV.
Phase 7 baseline G/Z and phase 8 signed G need investigation; do not clip G or certify it as golden conductance.
Walter reconstructed density is about 25–26% of input in phase 7; preserve the discrepancy.
Phase 9 models are uncalibrated examples; normalization area is a declared J→I conversion.
Phase 10 pinning uses a classical interlayer surrogate. Phase 11 completion does not establish physical accuracy.
No full mesh/frequency convergence certification was performed across this collection.
